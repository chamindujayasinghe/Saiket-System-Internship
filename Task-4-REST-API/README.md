# Task 4 — Basic REST API (User Entity)

A REST API built with **Node.js** and **Express** for the **SaiKet Systems Full Stack Development Internship**. It provides CRUD operations on a `User` entity with `name`, `email` and `age` fields.

> Data is kept **in memory** and resets when the server restarts. Task 5 connects this API to a database.

## Endpoints

Base URL: `http://localhost:3000`

| Method | Route | Description | Success |
|---|---|---|---|
| `GET` | `/api/users` | List all users | `200` |
| `GET` | `/api/users/:id` | Get one user | `200` |
| `POST` | `/api/users` | Create a user | `201` |
| `PUT` | `/api/users/:id` | Replace a user (all fields required) | `200` |
| `PATCH` | `/api/users/:id` | Update some fields | `200` |
| `DELETE` | `/api/users/:id` | Delete a user | `204` |

### User model

| Field | Type | Rules |
|---|---|---|
| `id` | integer | Generated by the server |
| `name` | string | Required, 2–100 characters (trimmed) |
| `email` | string | Required, valid format, unique (stored in lowercase) |
| `age` | integer | Required, 1–150 |
| `createdAt` / `updatedAt` | ISO date | Set by the server |

### Error responses

| Status | When |
|---|---|
| `400` | Validation failed, invalid id, unknown fields, or malformed JSON |
| `404` | User or route not found |
| `409` | Email already in use |
| `500` | Unexpected server error |

Errors are returned as JSON:

```json
{
  "error": "Validation failed",
  "details": ["email must be a valid email address", "age must be between 1 and 150"]
}
```

## Example Requests

```bash
# Create
curl -X POST http://localhost:3000/api/users \
  -H "Content-Type: application/json" \
  -d '{"name": "Chamindu Jayasinghe", "email": "chamindu@example.com", "age": 23}'

# Read
curl http://localhost:3000/api/users
curl http://localhost:3000/api/users/1

# Update
curl -X PATCH http://localhost:3000/api/users/1 \
  -H "Content-Type: application/json" -d '{"age": 25}'

# Delete
curl -X DELETE http://localhost:3000/api/users/1
```

## Run Locally

```bash
npm install
npm start        # http://localhost:3000
npm run dev      # restarts automatically on file changes
npm test         # runs the automated endpoint tests
```

## Testing with Postman

1. Start the server with `npm start`.
2. In Postman: **Import** → `postman_collection.json`.
3. Open the collection → **Run** to execute all 12 requests in order. Each request has test scripts that check status codes and response bodies.

The collection covers every endpoint's success case plus error cases: 404, invalid id, validation errors, duplicate email, malformed JSON, and unknown route.
